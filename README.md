## Projeto em destaque

### [Festa Junina — Sistema de Pedidos](#)
Sistema web completo para gerenciar pedidos de uma barraca de festa junina, criado para resolver um problema real de operação: substituir controle manual por um fluxo digital com emissão de ticket, fila de produção e confirmação automática por e-mail.

- Backend em Node.js/Express com banco SQLite, incluindo migrações idempotentes de schema.
- Painel administrativo com autenticação, fila de produção em tempo real, histórico, sorteio entre participantes de pré-venda e modo de edição para ocultar pedidos sem perder dados.
- Envio automático de ticket por e-mail via Nodemailer.
- API REST documentada, com rotas separadas para pedidos, pré-venda e operador.
